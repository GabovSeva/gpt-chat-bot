# 🤖 GPT-4o Chat Bot с анализом фото

Интерактивный чат-бот на базе Flask и OpenAI (через GitHub Models API), который умеет поддерживать диалог и анализировать загруженные изображения.

## 🌟 Основные возможности
* **Мультимодальность**: Бот понимает и текст, и картинки.
* **История диалога**: Запоминает контекст текущей беседы.
* **Логирование**: Все сообщения сохраняются в папку `user_logs`.
* **Адаптивный интерфейс**: Красивый веб-чат, который удобно открывать и с ПК, и с телефона.

## 🛠 Технологии
* **Backend**: Python, Flask, OpenAI SDK
* **Frontend**: HTML5, CSS3 (Flexbox/Animations), JavaScript
* **API**: GitHub Models (GPT-4o)

## 🚀 Как запустить

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd gpt-chat-bot
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения:**
   Создайте в корневой папке файл `.env` и добавьте туда свой токен:
   ```env
   GITHUB_TOKEN=ваш_токен_здесь
   ```

4. **Запустите приложение:**
   ```bash
   python app.py
   ```
   После этого чат будет доступен по адресу: `http://127.0.0.1:5000`

## 📁 Структура проекта
* `app.py` — основной серверный код и HTML-интерфейс.
* `uploads/` — папка для временно загруженных изображений.
* `user_logs/` — история переписки.
* `.gitignore` — исключает секретные ключи и временные папки из репозитория.
