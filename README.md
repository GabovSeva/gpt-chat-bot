# 🤖 GPT-4o Chat Bot с анализом фото

Интерактивный чат-бот на базе **Flask** и **OpenAI SDK**, использующий модели через GitHub Marketplace. Бот поддерживает текстовый диалог и умеет «видеть» изображения, которые ты загружаешь в чат.

## 🌟 Основные возможности
* **Анализ фото**: Загружай изображения, и GPT-4o расскажет, что на них.
* **Контекст общения**: Бот помнит историю сообщений внутри сессии.
* **Красивый UI**: Современный адаптивный интерфейс с анимациями (удобно и на ПК, и на мобилках).
* **Логирование**: Все переписки автоматически сохраняются в папку `user_logs` на сервере.

## 🛠 Технологии
* **Backend**: Python (Flask)
* **AI Engine**: GPT-4o (через GitHub Models API)
* **Frontend**: HTML5, CSS3, JavaScript (Vanilla)

## 🚀 Как запустить проект

### 1. Клонирование
```bash
git clone https://github.com
cd gpt-chat-bot
```

### 2. Получение API ключа
Для работы используется **GitHub Models**. Чтобы получить токен:
1. Перейдите на [страницу модели GPT-4o](https://github.com]([https://github.com/marketplace/models/azure-openai/gpt-4o/playground]).
2. Нажмите **"Get API key"**.
3. Используйте ваш Personal Access Token (Classic) с доступом к моделям.

### 3. Настройка окружения
Создайте в корне проекта файл `.env` и добавьте туда ваш ключ:
```env
GITHUB_TOKEN=ваш_токен_здесь
```

### 4. Установка и запуск
```bash
pip install -r requirements.txt
python app.py
```
После запуска открой в браузере: `http://127.0.0.1:5000`

## 📁 Структура проекта
* `app.py` — основной сервер и логика чата.
* `uploads/` — временное хранилище загруженных картинок (игнорируется Git).
* `user_logs/` — текстовые логи переписки (игнорируется Git).
* `.gitignore` — настройки защиты секретных данных.
