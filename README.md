# 🤖 GPT-4o Чат бот с анализом фото

Простой и красивый чат бот на базе GPT-4o. Поддерживает текстовые сообщения и анализ изображений.

## 🌟 Особенности

- 💬 Общение с AI на русском языке
- 📸 Анализ загруженных фотографий
- 🎨 Красивый адаптивный интерфейс
- 📝 Сохранение логов диалогов
